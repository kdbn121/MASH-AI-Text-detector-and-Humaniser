The five stage audit chain

The order is fixed in the skill, so a step cannot be skipped by accident. Every stage hands its output to the next one, and the proof run measures the same body twice.

1

Academic editor

Argument, structure, figures, references and the reviewer response are checked before a single sentence is rewritten.

agents/academic-editor.md
›
2

Live pattern check

The current Wikipedia pattern list is fetched and parsed, then the document is linted against what the page says now.

scripts/fetch_patterns.py
›
3

Humaniser

The named patterns, the tone and the machine rhythm are removed from your own prose, in sixteen passes.

scripts/transform.mjs
›
4

Similarity audit

Matched wording is measured against the source you name, then rewritten so the wording is yours.

scripts/audit.mjs
›
5

Proof run

Both measurements run again over the same body and the before and after numbers are reported.

pattern_lint.py + audit.mjs
Body only. The cover page, also called the title page, the contents page and the reference list are excluded from every measurement and every rewrite.
